# TUI SSH Workbench

一个用 Go、GoFrame 和 Bubble Tea 从零练习构建的 SSH 工作台，目标是提供 Xshell 风格的会话管理和交互式终端，以及 Xftp 风格的 SFTP/SCP、FTP/FTPS 文件传输、本地和远程文件预览与编辑。

当前仓库有 GoFrame 命令入口、Bubble Tea 主工作台、内置 Go 插件注册器与插件命令面板、本地 SQLite 主机目录，以及支持多标签和 pane 分屏的 SSH、Telnet、Rlogin、串口和本地交互终端。SSH pane 内可打开单栏远程文件工作区；从主机列表按 `f` 可连接 SSH/SFTP、SSH/SCP 或 FTP/FTPS，并打开双栏文件面板。

在独立 FTP/FTPS 双栏面板中，聚焦远程栏后按 `:` 可输入单行 FTP 原始命令并查看可滚动的服务器回复；`CWD` 和 `CDUP` 成功后会刷新目录。控制字符、超过 512 字节的命令，以及工作台负责管理的认证、TLS 协商、数据传输和连接设置命令会被拦截。其他命令由服务器按当前账户权限执行，请确认连接可信且账户权限合适；回复中的终端控制字符会被清理。

文件面板中按 `g` 可跳转到本地或远程的绝对路径，也可输入相对当前目录的路径；两台远程主机同步浏览时，跳转会沿用映射根限制，避免单栏跳出同步范围。

主界面按 `b` 可创建命名连接栏；在侧栏选中连接栏后按 `e` 重命名、按 `d` 删除。切到主机列表选中主机后按 `m` 可将它加入或移出连接栏；主机可以加入多个栏。在连接栏的主机列表中按 `1`–`9` 快速连接对应主机，按 `[` / `]` 调整当前主机顺序。连接栏及成员顺序保存在本机 SQLite 中，删除连接栏不会删除主机；删除主机时会自动清除它在各栏中的引用。

在主机列表按 `Space` 可跨分组选择多台主机，再按大写 `B` 批量编辑。编辑器可批量调整所属分组、收藏状态、备注、用户名、端口和 SSH 私钥路径，也可用名称模板批量改名；模板支持 `{name}`（原名）和 `{index}`（所选列表顺序），保存前显示预览。只有启用的字段会写入，其它连接设置保持原样。用户名和端口仅适用于 SSH、Telnet/Rlogin 与 FTP/FTPS 主机，私钥路径仅适用于 SSH；如果所选主机不支持启用的字段，整批修改会回滚。按 `Ctrl+T` 启用/停用文本字段，分组可用空格启用并用左右键选择；收藏状态用左右键在保持不变/全部收藏/全部取消之间切换。

TUI 界面文案默认使用中文。

在主界面按 `a` 可临时快速连接 SSH、Telnet、Rlogin 或 FTP/FTPS：支持 `user@host[:port]`、`ssh://user@host:port`、`sftp://user@host`、`scp://user@host`、`telnet://host:port`、`rlogin://user@host[:port]`、`ftp://user@host`、`ftps://user@host` 和 `ftps+implicit://user@host`。SSH 未填写用户名时使用当前系统用户名，Rlogin 未填写远程用户名时也会尝试使用当前系统用户名；FTP 未填写用户名时使用 `anonymous`。SFTP/SCP/FTP/FTPS 快速连接打开双栏文件面板，连接时交互输入密码；密码 URI 会被拒绝，临时连接不会写入主机目录。保存的 FTP/FTPS 主机可在编辑表单中选择主动或被动数据连接（默认被动）；主动模式要求 FTP 服务端能回连本机，防火墙或 NAT 可能阻止传输。`ftp://` 是明文传输，公网连接请使用 FTPS。需要复用或使用 ProxyJump 时请先通过 `n` 保存主机配置。Rlogin 默认端口为 513，且不加密账号和终端内容。

## 环境

- Go 1.25 或更高版本
- GoFrame CLI（可选，用于 `gf run`）

## 启动

```sh
go run .
# 或者使用 GoFrame CLI
gf run main.go
# 指定本地数据库位置（默认使用系统用户配置目录）
go run . -db ./workbench.db
```

默认读取当前目录的 `config.toml`；文件不存在时使用内置默认值。`[ssh]` 下可配置每一跳的连接/握手超时和 keepalive；`[ssh.proxy]` 可为 SSH 终端、SFTP/SCP 和计划传输配置全局 HTTP CONNECT、SOCKS4 或 SOCKS5 出站代理。它只代理 SSH 链路的首个 TCP 跳点；配置 ProxyJump 时，首台跳板机经出站代理连接，后续跳点通过前一台 SSH 主机转发。SOCKS4 仅支持 IPv4，由本机解析目标域名；`username` 会作为 SOCKS4 user ID 发送，不能配置密码。HTTP/SOCKS5 需要认证时，用户名放在配置文件中，密码通过 `password_env` 引用环境变量，避免明文写入 TOML。连接超时范围为 1–600 秒，keepalive 间隔范围为 0–3600 秒（0 关闭 keepalive），响应超时范围为 1–120 秒。通过 `--config` 指定其他配置文件：

```toml
[ssh]
connect_timeout_seconds = 15
keepalive_interval_seconds = 30
keepalive_timeout_seconds = 10

[ssh.proxy]
type = "socks5" # none、http（CONNECT）、socks4 或 socks5
address = "127.0.0.1:1080"
username = "proxy-user"
password_env = "WORKBENCH_SSH_PROXY_PASSWORD"

[appearance]
# 内置配色：default、nord、dracula、solarized-dark、high-contrast、catppuccin-mocha、tokyo-night、gruvbox-dark、one-dark。
scheme = "nord"

[appearance.colors]
# 可选覆盖单个颜色，格式为 #RRGGBB。
accent = "#58C4D8"

[notifications]
# 开启文件传输完成后的桌面系统通知；默认关闭。
enabled = false

[terminal]
# 收到远端 BEL 时显示短暂的 TUI 状态提示；可设为 visual 或 off。
bell = "visual"
# 终端列数与行数；0 表示跟随 pane。固定尺寸可为远端 TUI 提供稳定布局。
columns = 0
rows = 0

[terminal.keyboard]
# Alt 键作为 Meta 时在按键序列前加 ESC；设为 off 可关闭。
meta_key_emulation = "escape"
# 可覆盖 F1–F20，以及退格键和 Delete 键发送的终端序列。
backspace_sequence = "\u007f"
delete_sequence = "\u001b[3~"

[terminal.keyboard.function_keys]
# 只填写需要覆盖的按键；值是发送给远端的文本/控制序列。
f1 = "\u001bOP"
f13 = "\u001b[25~"

[workspace]
leader = "ctrl+g"
restore_last_on_startup = false
show_footer_shortcuts = true
status_bar_items = ["leader", "session", "traffic", "split", "command_history", "quick_command", "scheduled_transfers", "sftp", "help", "close_pane"]

[workspace.bindings]
# 修改左右分屏键；其他未列动作仍使用默认键位。
split_vertical = "j"
```

将 `show_footer_shortcuts` 设为 `false` 可隐藏 SSH 工作区底部的常驻快捷键提示；会话名、流量和临时状态信息仍会显示。主界面按 `S` 可切换此项，选择会保存到本机 SQLite 设置中，并覆盖配置文件里的默认值。

HTTP 代理使用 CONNECT 隧道，SOCKS4 使用 IPv4 和无密码的 user ID，SOCKS5 支持无认证和用户名/密码认证；SOCKS4 目标域名由本机解析，SOCKS5 目标主机名交由代理解析。启动程序前将 HTTP/SOCKS5 代理密码设置到对应环境变量。代理认证信息不会写入 SSH 会话数据库或传输计划；SOCKS4 user ID 和未加密的 HTTP/SOCKS5 认证字段在本机与代理之间不受传输层加密保护。

工作区快捷键支持在 `config.toml` 的 `[workspace]` 与 `[workspace.bindings]` 中重映射。前缀键为 `Ctrl` 加一个英文字母；与终端控制字符或内置快捷键冲突的组合会被拒绝。同一操作界面中的动作键不能互相冲突。只填写需要修改的动作即可，设为空字符串可禁用动作。默认按前缀再按 `Ctrl+E`，可将当前 pane 与下一个 pane 交换位置；也可拖动 pane 标题栏到另一个 pane 上交换。状态栏项目可用 `status_bar_items` 调整顺序并隐藏；支持 `leader`、`session`、`traffic`、`split`、`command_history`、`quick_command`、`scheduled_transfers`、`sftp`、`help` 和 `close_pane`，列表设为空可隐藏全部默认项。`session` 和 `traffic` 显示活动终端的主机名及该终端通道收发字节数。搜索、错误、录制和滚动等临时状态仍会优先显示。设置 `restore_last_on_startup = true` 可在启动时自动恢复并重连上次工作区；它优先于默认会话，未开启时仍可在主机列表按 `R` 手动恢复。恢复只包含已保存主机和布局，会按正常 SSH 指纹及认证流程重新连接。进入工作区后按前缀再按 `?`，可查看完整的当前键位表。

在会话工作区按 `Ctrl+G` 后按 `Ctrl+L` 可锁定屏幕；首次使用会要求设置并确认至少 8 个字符的密码。锁屏时隐藏终端内容、阻止键盘/粘贴/鼠标输入，连接和远端输出仍保持活动。按 `Ctrl+G` 后按 `Ctrl+P` 可验证当前密码后更改密码，输入新密码时按 `Ctrl+D` 可移除。密码使用 scrypt 派生校验值，只将校验值保存到操作系统钥匙串；忘记密码时需从系统钥匙串删除 `tui-ssh-workbench` 的 `security:screen-lock:v1` 条目后重新设置。可选 `[security] auto_lock_minutes = 15` 在空闲指定分钟后自动锁屏；设为 `0`（默认）关闭。自动锁屏只有在已设置有效锁屏密码时才会启用。

终端按键映射可在 `[terminal.keyboard]` 配置：`function_keys` 支持 `f1`–`f20`，未配置的键保留 xterm 默认序列；将某项设为空字符串可禁用该功能键。`backspace_sequence`、`delete_sequence` 可分别覆盖退格和 Delete 序列，`meta_key_emulation` 接受 `escape` 或 `off`。序列使用 TOML 字符串转义（例如 `\u001b` 表示 ESC），上限 256 字节；发送时会按当前主机的终端编码转换。

工作台主界面按 `T` 可选择并保存配色方案，选择保存在本地 SQLite 设置中。也可在 `[appearance]` 选择 `default`、`nord`、`dracula`、`solarized-dark`、`high-contrast`、`catppuccin-mocha`、`tokyo-night`、`gruvbox-dark` 或 `one-dark`，并在 `[appearance.colors]` 用 `#RRGGBB` 覆盖个别界面颜色。配置文件中的自定义覆盖优先应用；工作台配色只控制自身界面，终端程序的 ANSI 颜色仍由终端模拟器控制。

远端终端发送 BEL（`\a`）时，工作区默认在状态栏显示 800 毫秒的视觉响铃提示。可在 `[terminal]` 将 `bell` 设为 `off` 关闭；是否播放声音由外层终端模拟器控制。

终端输出高亮可在 `config.toml` 中添加多个 `[[terminal.highlights]]` 规则。`pattern` 使用 Go RE2 正则并逐行匹配 VT 模拟器处理后的可见文本，因此 ANSI 颜色控制序列和分包读取不会影响匹配；规则覆盖当前屏幕与滚屏历史，不跨行匹配。可选 `ignore_case`、`foreground`、`background` 和 `bold`；颜色须为 `#RRGGBB`，每条规则至少设置一种样式，最多 32 条。规则按配置顺序应用，后面的规则只覆盖它设置的样式项。选中的终端搜索结果仍显示在规则高亮之上。

终端触发器使用 `[[terminal.triggers]]` 配置，最多 32 条，`pattern` 是 Go RE2 正则。触发器检查已剥除 ANSI 控制序列的终端输出，并可匹配跨读取分包的提示符；每条规则对同一匹配只执行一次，2 秒冷却用于避免自动发送循环。支持 `action = "message"`（在 pane 状态栏显示 `text`）、`action = "bell"`（按终端响铃设置提示）、`action = "send"`（向当前终端输入 `text`，`send_enter = true` 时追加回车）和 `action = "script"`（运行下方版本 1 JSON `expect/send` 脚本）。脚本路径支持 `~`，相对路径按启动程序时的当前目录解析；每步使用 Go RE2 匹配并有超时，发送内容可使用 `{{user}}` 和钥匙串凭据 `{{password}}`。启动命令或登录脚本仍在运行时会跳过新触发的发送/脚本并显示状态提示。`send` 和脚本动作会自动向当前终端写入内容，可能直接执行 Shell 命令；启用前请核对匹配条件与发送内容，不要把密码写入普通 TOML 配置。当前支持项目自有的 JSON 脚本格式，不执行 Xshell JScript/VBScript 或任意外部程序。

```toml
[[terminal.triggers]]
name = "confirm-deploy"
pattern = "Continue with deployment\\?"
ignore_case = true
action = "send"
text = "yes"
send_enter = true

[[terminal.triggers]]
name = "deployment-flow"
pattern = "Deployment requested"
action = "script"
script_path = "~/scripts/deploy-confirm.json"
```

```json
{
  "version": 1,
  "steps": [
    { "expect": "Continue with deployment\\?", "send": "yes", "timeout_seconds": 30 },
    { "expect": "Password:", "send": "{{password}}", "timeout_seconds": 30 }
  ]
}
```

`[terminal]` 的 `columns` / `rows` 可分别固定终端宽高，默认 `0` 表示跟随 pane。固定尺寸大于当前 pane 时，状态栏会显示虚拟终端尺寸和可见范围；按 `Ctrl+G` 后按 `[` / `]` 左右移动视口，按 `{` / `}` 上下移动。四个动作可在 `[workspace.bindings]` 自定义。终端尺寸范围为 20–1000 列、5–500 行；本地终端和支持窗口尺寸协商的连接会同步尺寸，串口等不支持尺寸协商的连接仅使用本地终端模拟器尺寸。

每台主机的终端编码可在会话 pane 菜单中循环切换，设置会保存到 SQLite 并随 JSON 会话目录导出。当前支持 UTF-8、GBK、GB18030、Big5、Shift_JIS 和 Windows-1252；输入和粘贴会转成主机编码，遇到编码无法表示的字符会拒绝发送，避免静默损坏。旧 JSON 会话目录没有此字段时按 UTF-8 导入。每个终端 pane 标题还会显示该终端通道自连接以来收发的字节量；SSH 传输开销、独立 SFTP 通道和端口转发流量不计入该数字。

终端模拟器会将 CSI/OSC 状态查询的应答回写到对应连接，支持依赖光标位置、终端颜色等查询初始化的全屏 TUI；关闭 pane 时会释放应答通道。

会话目录可以使用版本化 JSON 文件备份或迁移：

```sh
go run . --export-sessions ./sessions.json
go run . --import-sessions ./sessions.json
# 与默认数据库不同的位置
go run . --db ./workbench.db --export-sessions ./sessions.json
# 导出为 Xshell 可读取的 .xsh 会话目录
go run . --export-xshell ./xshell-sessions
# 导出为 Xftp 会话目录
go run . --export-xftp ./xftp-sessions
```

`--import-sessions` 也支持单个 Xshell `.xsh`、Xftp `.xfp` 文件，或递归导入混合原生会话目录；目录层级会映射为多级主机分组。`.xsh` 支持 SSH/SSH2、Telnet、Rlogin 和 SERIAL；串口 COM 端口、帧参数、None/XON-XOFF/RTS-CTS 流控，以及 UTF-8、GBK、GB18030、Big5、Shift_JIS、Windows-1252 对应的 `CodePage` 均可映射（CP936 映射为 GBK，CP54936 映射为 GB18030）。Xshell 会话输出代码页与键盘输入编码分开保存，键盘输入保持 UTF-8；真实 Xshell 客户端往返仍待验收。通用 JSON 会话目录当前为版本 12，可保存串口配置、独立的输出/输入终端编码、FTP 主动/被动数据连接模式以及分组远程起始目录；本地起始目录和分组本地默认属于机器本地设置，不参与导出。SSH 和 FTP/FTPS 主机及其分组可设置本地与远程起始目录，主机字段留空时按本地、远程字段分别继承最近祖先设置；本地分组目录只保存在本机，远程分组目录随会话目录导出；本地路径支持 `~`，相对路径以启动工作台时的目录为基准，远程相对路径以服务器报告的当前目录为基准。`.xfp` 读取 SFTP、SCP 与 FTP 的协议、主机、端口、用户名、会话名和备注；SCP 可在共享双栏文件面板中浏览、搜索、预览/编辑、管理文件，并进行本地/远程和远程/远程传输。SCP 文件面板通过远端 POSIX shell 和 GNU/BSD `stat` 读取目录元数据；Windows 远端 Shell、控制字符文件名和缺少兼容 `stat` 的服务器不支持。密码、启动脚本、代理等不支持字段不会进入本机数据库。支持 UTF-8 和带 BOM 的 UTF-16 LE/BE。

`--export-xshell DIR` 会把可表达的 SSH、Telnet、Rlogin 主机导出为 Xshell `.xsh` 目录，保留分组层级。目标目录必须不存在；POSIX 系统目录权限为 `0700`、会话文件权限为 `0600`。密码和本机凭据引用不会导出。包含 ProxyJump、启动脚本、X11 转发、端口转发规则或不支持协议（包括串口）的主机会被跳过，并逐项显示原因。导出文件已通过本项目解析器往返验证，仍需在 Xshell 实际导入验收。

`--export-xftp DIR` 会导出 SFTP、SCP 与明文被动模式 FTP `.xfp` 会话；FTPS、主动模式 FTP、ProxyJump 和不支持协议会被跳过。与 Xshell 导出一样，目标目录必须不存在，秘密不会导出。`.xfp` 读写已通过本项目解析器往返测试；当前还需用脱敏的真实 `.xfp` 样本校准字段布局，并在 Xftp 中实机导入验收。

导出包含主机、嵌套分组与分组远程起始目录、ProxyJump 关系、收藏状态、SSH X11 转发、FTP 主动/被动数据连接模式、远程起始目录、串口设备参数与流控设置，以及已保存的端口转发规则。当前 JSON 格式为版本 12，并可读取版本 1 至 11 文件。最近连接时间和本地起始目录仅保存在本机数据库，不参与导出。POSIX 系统会以 `0600` 权限新建文件（Windows 使用当前目录 ACL），若目标已存在会报错且不会覆盖。密码、本机凭据引用和启动脚本不会导出；导入遇到 ID、分组名称或 ProxyJump 循环冲突时整批回滚，相同数据重复导入不会重复创建记录。

## 命令行单次文件传输

可以直接使用已保存的 SSH/SFTP、SCP 或 FTP/FTPS 主机上传、下载文件或目录，不启动 TUI。所有文件协议均支持递归目录传输；SCP 目录工作区依赖远端 POSIX shell 和 GNU/BSD `stat`，远端提供 SHA-256 工具时可校验并续传文件：

```sh
go run . --transfer \
  --transfer-host prod \
  --transfer-direction upload \
  --transfer-local ./app.tar.gz \
  --transfer-remote /srv/app.tar.gz

go run . --transfer \
  --transfer-host prod \
  --transfer-direction download \
  --transfer-local ./backup.tar.gz \
  --transfer-remote /srv/backup.tar.gz \
  --transfer-overwrite
```

`--transfer-host` 接受主机 ID 或不区分大小写的唯一名称；名称重名时必须用 ID。上传时本地路径是源，下载时本地路径是目标。默认不覆盖目标文件，添加 `--transfer-overwrite` 才会覆盖。认证秘密从系统钥匙串读取；SSH/SCP 仍要求主机指纹已信任，FTP/FTPS 不会把密码放入命令行参数。按 `Ctrl+C` 会取消传输。需要指定其他数据库时可增加 `--db ./workbench.db`。

递归传输跳过本地符号链接和特殊文件；SCP 下载会拒绝包含远程符号链接或特殊文件的目录树。SCP 单文件通过隐藏暂存文件提交，目录内按文件逐项提交；单文件上传和下载在取消或中断后会保留暂存内容，下次传输会校验已有前缀后续传；无法安全校验时使用新的暂存名从头传，未完成文件不会替换目标。SCP 递归目录下载也会逐文件校验续传：已完整下载且内容匹配的文件会跳过，中断文件会在匹配源文件前缀后续传；续传标记只允许当前源路径和本地目标继续，普通已有目录仍需覆盖确认。传输会保留 rwx 权限和修改时间。

### OpenSSH SFTP/SCP 互操作测试

安装 OpenSSH server、`ssh-keygen`、`ssh-agent`、`ssh-add`、Python 3 和 Go 后，可在 macOS/Linux 上运行：

```sh
scripts/verify-openssh-scp.sh
```

脚本会生成临时客户端密钥、OpenSSH 用户 CA 和签名证书，在 `127.0.0.1` 随机端口启动隔离的 `sshd` 与临时 agent；分别用 agent 公钥和 CA 用户证书验证 SFTP/SCP 工作区的目录操作、上传/下载、编辑保存、权限修改和递归传输。证书用私钥旁的 `-cert.pub` 文件自动配对，证书验收时禁用 agent，确保认证确实走 CA 证书。脚本不读取或改写现有 SSH 配置、密钥和 `known_hosts`；退出时会停止进程并清理临时密钥。脚本要求以普通用户运行。此测试证明与本机 OpenSSH 服务端的互操作，不替代其他 SSH 服务端和 Xshell/Xftp 客户端的实机验收。

### XMODEM / YMODEM

在终端 pane 中按工作区前缀后按 `!`，或打开 pane 菜单选择 **XMODEM / YMODEM 传输**。先在远端运行发送或接收命令并等它进入等待状态，再在工作台选择方向并确认本地路径。XMODEM 的 `lrzsz` 接收命令要指定目标文件，例如 `lrx -X -y received.bin`；远端发送用 `lsx -X file.bin`。YMODEM 批量接收用 `lrb -g -y`，发送用 `lsb -g file1 file2`。XMODEM 每次传输一个文件，YMODEM 支持批量文件。XMODEM 不带文件大小，标准接收端会保留最后一块的 `0x1a` 填充；本工具接收时会剥除尾部填充，因此以该字节结尾的文件存在固有限制；YMODEM 使用头部文件大小保留原始字节。协议状态机通过了本地往返测试，以及 `lrzsz` 0.13.1 的 PTY 外部四方向互操作测试（`lrx`、`lrb`、`lsx`、`lsb`）。

安装 `lrzsz` 并确保上述四个程序都在 `PATH` 中后，可重复运行外部互操作测试；未安装时该测试会跳过：

```sh
go test ./internal/infra/xymodem -run TestInteroperatesWithLRZSZ -count=1
```

### FTP/FTPS 外部服务端互操作测试

安装 Python 3、OpenSSL 和 Go，并允许 pip 下载临时测试依赖后，可运行：

```sh
scripts/verify-ftp-interop.sh
```

脚本会在临时虚拟环境中安装 pyftpdlib，分别启动本机明文 FTP、显式 FTPS 和隐式 FTPS 服务端，验证隐藏文件列举、TLS 控制/数据连接、上传/下载、编辑保存、递归搜索、续传和目录传输。它还确认服务端拒绝非标准 `LIST -a` 后，客户端会重新连接并使用服务器支持的目录列表命令；临时证书、账户和文件均在退出时清理。此脚本不测试 FXP 或第三方商业 FTP 服务端。

主界面按 `q` 或 `Ctrl+C` 退出；SSH pane 中的 `Ctrl+C` 会发给远端进程。会话标签在返回主机列表后仍保持连接，退出应用时关闭所有 SSH 会话。

主界面快捷键：

- `g`：在当前分组下新建分组；当前为“All hosts”时创建顶层分组。
- `n`：新建主机，默认放入当前分组；当前为“All hosts”时保存为未分组主机。
- `e`：编辑当前选中的主机或分组；编辑分组时可调整父级分组、SSH 认证配置继承及文件面板起始目录。
- `d`：删除当前选中的主机或分组；删除前会二次确认。分组必须为空才能删除；仍被其他主机作为跳板机引用，或仍有计划传输引用的主机，需先解除关联。
- `v`：收藏或取消收藏当前主机。左侧“收藏”视图列出已收藏主机；“最近连接”按最近一次成功连接时间排序。
- `s`：将当前主机设为默认会话或清除默认会话。主机卡片会标记默认项；设置保存在本机 SQLite，不随会话目录导出；下次启动工作台时会自动开始连接，FTP 主机会先要求输入密码。
- `1`–`9`：快速连接收藏快捷栏前 9 台主机；主机卡片会显示对应编号。
- `[` / `]`：将当前收藏主机在快捷栏中前移或后移，顺序保存在本地 SQLite。
- `c`：管理当前 SSH 或 FTP/FTPS 主机的系统钥匙串凭据；输入凭据后按 `Enter` 保存/更新，按 `Ctrl+D` 删除。
- `Ctrl+K`：打开 SSH 密钥管理器，查看本应用生成密钥的算法、指纹和加密状态；可创建新密钥、迁移主机/认证配置档对新密钥的引用，或删除未被引用的密钥。轮换时先创建新密钥并把 `.pub` 公钥部署到列出的服务器，再选中旧密钥按 `m`；迁移使用单个 SQLite 事务，旧密钥保留。该管理器只处理 `~/.ssh/workbench_*`，不会扫描或删除其它身份文件。
- `Ctrl+Shift+H`：管理本应用 `known_hosts` 中的信任记录。`i` 导入 OpenSSH `known_hosts` 文件，先预览并确认后去重合并；`e` 导出到新文件（权限 0600，拒绝覆盖已有文件）；`d` 移除所选记录行，移除后再次连接会重新显示指纹确认。操作会保留信任库中的其他主机密钥和注释。已知主机指纹变化时会显示旧、新指纹，按 Enter 确认后原子替换旧指纹并重连；按 Esc 取消不会更改记录。通配符、证书授权和撤销记录不会自动替换，需要手动检查。
- `Ctrl+P`：管理可复用的 SSH 认证配置档；可保存用户名、私钥路径，并把密码/私钥口令安全地存进系统钥匙串。编辑 SSH 主机时，在“认证配置”字段用 `←` / `→` 绑定配置档；编辑分组时，可在“SSH 认证配置（继承）”字段为该分组及其子分组设置默认配置，也可设置本地和远程文件面板起始目录。主机直接绑定的配置优先于最近祖先分组的配置；配置档中的非空用户名、私钥路径和凭据会覆盖主机自身设置，空字段沿用主机值。认证配置档与分组绑定只保存在本机，不随会话目录导出。
- `f`：连接当前选中的 SSH/SFTP、SSH/SCP 或 FTP/FTPS 主机并打开独立双栏文件面板；本地终端不支持。
- `t`：打开计划传输管理器，新增、编辑、立即执行、启用/停用、删除和刷新上传/下载计划。
- `Enter`：连接当前选中的 SSH、Telnet、Rlogin、串口主机或本地终端并新建会话标签；选中 FTP/FTPS 主机时打开双栏文件面板。也可以单击主机卡片选择、双击连接。SSH 首次连接会显示 SHA256 主机指纹供确认；已知指纹变化时展示旧、新指纹，核对后确认替换并重连。
- `Ctrl+O`：在主机列表和当前会话工作区之间切换。
- `R`：恢复上次退出时打开的工作区；只保存标签/pane 拓扑和已保存主机 ID，不保存终端内容或凭据。恢复时会重新建立连接并按正常流程认证；主机已删除或暂时无法连接时会显示错误或允许在对应 pane 重试。也可在 `[workspace]` 中开启 `restore_last_on_startup = true` 自动恢复。
- `l`：在主机列表打开已保存布局；在会话工作区按 `Ctrl+G` 后按 `=` 打开布局管理器。布局可命名保存当前标签、pane 分屏比例、活动标签/pane 和同步输入状态；按 `Enter` 恢复，`s` 保存，`d` 删除。恢复会把布局中的主机引用解析到当前主机目录，并依次重新连接；若引用的主机已删除或包含 FTP 主机，会在修改工作区前拒绝恢复。布局只保存主机 ID 和界面拓扑，不含凭据、终端输出或历史记录。同名保存会更新原布局。
- 表单中用 `Tab` / `↑↓` 切换字段，类型、跳板机、认证配置、分组以及串口校验位/停止位字段用 `←→` 选择，`Enter` 前进或保存，`Esc` 取消。编辑串口设备路径时按 `Ctrl+P` 可异步检测并选择本机设备；也可以继续手动输入路径。分组的认证配置字段可清空以继续继承父级配置，主机直接绑定的配置会覆盖分组继承。SSH 主机可以选择一台跳板机；跳板机本身也可设置跳板机来构造多跳链路。新增主机时可以把类型设为“本地终端”；启动时会运行当前用户的登录 Shell，工作目录沿用启动工作台时的目录。SSH 主机表单还可填写一条连接后命令；命令会在 SSH 终端首次收到输出时发送一次，只接受单行、不超过 1024 字符，并且不会导出到会话文件。
- SSH 主机资料保存名称、地址、端口、用户名、分组、备注和可选的本机私钥路径；SSH 主机还可开启 X11 转发。使用 X11 时，本机需要可用的 `DISPLAY`、`xauth` 和 X Server，远程 sshd 也必须允许 X11 转发。转发请求使用临时伪 cookie，收到 X11 通道后校验并替换成本机 cookie；当前只连接本机 Unix socket 或回环 TCP DISPLAY。Xshell `.xsh` 不支持无损表达此设置，导出会跳过启用了 X11 的主机。按主机设置的转发不影响 SFTP/SCP 连接。私钥生成与钥匙串说明见下文：在私钥路径字段按 `Ctrl+G` 可生成 Ed25519 或 RSA-3072 密钥对，选择是否用口令加密私钥。已有同名文件不会覆盖；POSIX 系统将私钥设为仅当前用户可读（0600），Windows 使用文件系统继承的 ACL；公钥另存为 `.pub` 并显示安装提示。加密口令只在生成期间保留于内存，连接时需重新输入或存到钥匙串。私钥内容不会写入 SQLite 或会话导出文件。`~` 和相对路径分别按用户主目录与程序启动目录解析。密钥管理器只列出 `~/.ssh/workbench_*`，阻止删除仍被主机或认证配置档引用的密钥；外部密钥仍可通过主机配置私钥路径使用。主机表单不收集登录密码；在主机列表按 `c` 可把 SSH 登录密码 / 私钥口令或 FTP/FTPS 密码保存在系统钥匙串，SQLite 只保存随机凭据引用。更新时先写入新钥匙串条目，再更新 SQLite 引用；若 SQLite 更新失败，会尝试删除新条目并保留旧引用。
- 可把主机类型设为 Rlogin（默认端口 513）。本机用户名作为客户端用户名，主机配置中的用户名作为远程用户名；支持终端尺寸更新。Rlogin 不加密，且依赖服务器的旧式信任配置，只应在隔离、可信网络使用。快速连接可写 `rlogin://user@host[:port]`。
- 可把主机类型设为串口终端，按 `Ctrl+P` 检测并选择本机串口设备，也可手动填写设备路径；波特率、数据位、校验位、停止位和 None/XON-XOFF/RTS-CTS 流控均可配置。串口没有网络端口或远端窗口尺寸协商；实体串口设备及 Xshell 客户端互操作仍待验收。
- 可把主机类型设为 FTP/FTPS。安全模式可选明文 FTP、显式 FTPS 或隐式 FTPS；未保存凭据时每次连接输入密码，仅保留在当前文件面板内存中。已保存的 FTP 密码从系统钥匙串读取，不写入数据库或会话导出。明文 FTP 会以未加密方式传送账号、密码和文件，请仅用于可信网络；公网连接优先使用 FTPS。
- SSH 连接优先尝试 SSH agent、主机指定的私钥和默认路径下的私钥；主机指定的私钥支持加密 OpenSSH/PEM 密钥，口令复用本次输入或钥匙串凭据。若私钥旁存在 OpenSSH 默认命名的 `私钥路径-cert.pub`，会将匹配的 user certificate 与私钥配对认证；不匹配、损坏或 host certificate 会明确报错。若主机或跳板机配置了钥匙串凭据，会按连接链逐台读取并尝试。认证失败时会明确显示当前需要认证的跳板机或目标主机，并可逐台输入登录密码或私钥口令。服务器也可使用键盘交互式认证（包括多轮 MFA / OTP 质询），按提示逐项输入，标记为隐藏的答案会遮罩。通过跳板连接时会逐跳校验主机指纹；未选择保存的凭据只保留到本次连接成功或取消，不写入数据库或日志。
- 会话工作区默认使用 `Ctrl+G` 作为快捷键前缀，可按前文配置自定义前缀和动作键。默认按 `Ctrl+G` 后再按 `v` / `h` 左右或上下分屏，随后从主机选择框选择新 pane 要连接的 SSH、Telnet、Rlogin、串口主机或本地终端；选择框中按 `↑` / `↓` 或 `j` / `k` 移动，`Enter` 连接，`Esc` 取消。按 `Ctrl+G` 后按 `s` 查看当前 pane 的终端历史；回看时用 `↑` / `↓` 滚动、`PgUp` / `PgDn` 翻页、`Home` / `End` 定位，`Esc` 返回实时终端。也可在未启用远端鼠标模式时用滚轮回看。按 `Ctrl+G` 后按 `/` 搜索当前 pane 的历史和屏幕；默认是大小写不敏感的文本搜索，输入时按 `Ctrl+R` 可切换到 Go RE2 正则模式（正则默认忽略大小写，支持 Go RE2 语法）。按 `Enter` 查找，用 `n` / `N` 逐项跳转结果，同一行的多个匹配也会分别高亮；结果最多显示 10000 项。`e` 修改查询，`Esc` 返回实时终端。按 `Ctrl+G` 后按 `u` 清除当前 pane 的画面和本地回看历史；操作只清理本地 VT 缓冲，不会向 Shell 发送命令。按 `←` / `→` 切 pane；按 `n` / `p` 切换标签；按 `1`…`9` 跳转标签；按 `c` 关闭 pane；按 `w` 关闭标签；按 `m` 打开当前 pane 菜单；按 `t` 打开当前标签菜单；按 `=` 管理已保存布局；按 `o` 返回主机列表。按 `Esc` 取消快捷键前缀。
- 按 `Ctrl+G` 后按 `y` 查看当前 pane 的命令历史，按 `↑` / `↓` 选择，按 `Enter` 或 `c` 通过 OSC 52 请求复制到系统剪贴板（需外层终端支持），再粘贴回终端；按 `x` 后再按 `y` 清空。历史最多保留 100 条，仅保存在当前进程内，关闭 pane 或退出程序后消失。只有终端随后回显出匹配命令时才记入历史，隐藏的密码提示不会被记录；命令行中直接写入的密码仍可能被回显并记录，请在面板中清空。
- 在 SSH pane 中按 `Ctrl+G` 后按 `b` 开始或停止当前 pane 的终端输出记录，也可从 pane 右键菜单切换。按 `Ctrl+G` 后按 `g`，或从 pane 右键菜单选择“查看终端输出日志”，可浏览所有日志、按文件名筛选并安全预览 VT 输出；预览最多保留 5000 行回看缓冲。预览默认按 UTF-8 解码，乱码时按 `Ctrl+U` 循环切换 UTF-8、GBK、GB18030、Big5、Shift_JIS 和 Windows-1252；所选编码仅用于当前预览，不写入原始日志。日志保存在用户配置目录的 `tui-ssh-workbench/logs`，只记录远端原始 VT 输出，不记录键盘输入；POSIX 平台使用 0700 目录和 0600 文件，Windows 日志放在用户配置目录下并继承其 ACL。默认每段最多 100 MiB、每次录制保留 5 段，达到大小会自动轮转并移除该次录制中最旧的分段；全局默认总容量为 1 GiB、最长保留 90 天，可在 `config.toml` 的 `[logging]` 调整。创建日志时、录制期间每分钟及关闭日志后会清理过期日志，再按最旧优先清理非活动日志；活动日志及其轮转段会受到保护，因此录制期间总容量可能暂时超限。`redact_patterns` 可配置 Go RE2 有界正则，匹配的可打印终端输出在落盘前替换为 `[REDACTED]`，终端实时显示不变。为限制缓存，规则必须是有限宽度（用 `{min,max}`，不支持 `*`、`+`、行/文本锚点和单词边界）；终端控制序列会保留。未配置规则或内容不匹配规则时，日志仍可能含敏感信息，界面会提示。写入队列拥塞或磁盘错误会停止记录并显示错误。日志浏览器中选中一个分段后按 `d`，再按 `Enter` 或 `y` 确认删除；按 `Esc` 或 `n` 取消。仍在记录的会话及其轮转分段不能删除。
- 在已识别 Shell 提示符的终端中，按 `Ctrl+G` 后按 `Ctrl+B`，或从 pane 右键菜单开始 Shell 脚本录制；再次执行该动作会停止并保存为可复用的版本 1 JSON `expect/send` 脚本。它记录用户提交的单行 Shell 命令，不记录任意交互按键；密码、密钥口令等敏感提示中的输入会跳过。普通命令参数仍可能包含密码或令牌，录制前请检查命令，保存后也请检查脚本。文件写入用户配置目录下的 `tui-ssh-workbench/scripts/recordings`，POSIX 文件权限为 `0600`；关闭 pane/标签、连接断开或退出程序时会自动尝试保存，写入失败会保留录制状态并阻止主动关闭/退出。录制脚本可在主机登录脚本设置中选择复用；它不兼容 Xshell JScript/VBScript。
- 多 pane 标签页可按 `Ctrl+G` 后按 `i` 开启/关闭同步输入。开启后，键盘输入和粘贴会发送到当前标签页内所有已连接 pane，底栏会持续显示目标数量；不同 pane 按各自终端的 bracketed-paste 模式接收粘贴。每个标签页独立保存此开关，默认关闭。
- 按 `Ctrl+G` 后按 `q` 打开快速命令面板。命令存储在本地 SQLite，可新增、编辑和删除，支持多行内容；选中后按 `Enter` 会粘贴并执行。默认发送到当前 pane；同步输入开启时，会显示并发送到当前标签页内所有已连接 pane。
- 计划传输在主机列表按 `t` 管理，在会话工作区按 `Ctrl+G` 后按 `d` 管理。每项可选择 SSH/SFTP、SSH/SCP 或 FTP/FTPS 主机、上传/下载、本地和远程文件或目录、Cron 表达式、时区、启停状态和冲突覆盖策略；本地路径会保存为绝对路径。时区可填 IANA 名称（如 `Asia/Shanghai`），默认为运行机器本地时区。`@every` 使用固定间隔。按 `i` 可排入一次立即执行，不会开启已停用的周期计划，也不会改变下一次计划时间；任务开始前可删除该任务以取消排队。保存 FTP 密码到系统钥匙串后，任务可在非交互模式使用；SSH 主机必须已在 `known_hosts` 中信任。
- 工作台打开期间会自动运行计划任务，最多并发 3 项；退出工作台会取消正在执行的任务并记录结果。需要在工作台关闭后继续执行时，可另开进程运行 `go run . --run-scheduled`；自定义数据库路径时需使用同一个 `--db` 参数。工作台每 5 秒检查共享数据库并显示短时完成提示。配置 `[notifications] enabled = true` 后，交互传输、CLI 单次传输、工作台内置 runner 和独立 runner 会尝试发送桌面通知；系统没有可用通知服务时不影响传输结果。
- 按 `Ctrl+G` 后按 `x` 打开插件命令面板，可按命令名或描述搜索；选中后按 `Enter` 异步运行，`Esc` 请求取消。默认命令 `system.runtime` 显示 Go 版本和运行平台。插件输出最多 64 KiB，并在显示前剥离终端控制序列。当前仅加载编译进程序的可信 Go 插件，处理器应响应取消上下文；独立进程隔离和能力授权仍待实现。
- 终端中鼠标左键双击可选择当前单词；按住 `Shift` 并拖动可选择当前可见文本，按住 `Shift+Alt` 拖动可作矩形选区。远端程序启用鼠标跟踪时，普通点击仍发送给远端程序。Windows/Linux 按 `Ctrl+Shift+C`，macOS 按 `⌘+Shift+C` 复制选区；应用先写入本机系统剪贴板（macOS 使用 `pbcopy`，Linux 尝试 `wl-copy`、`xclip`、`xsel`），不可用时回退到 OSC 52。Windows/Linux 按 `Ctrl+Shift+V`，macOS 按 `⌘+V` 读取终端剪贴板并粘贴。也可从 pane 右键菜单选择“复制当前选区”。按 `Esc` 清除选区。
- 按 `Ctrl+G` 后按 `a` 打开 Compose Pane。可在发送前编辑和预览多行内容；面板打开时会固定目标为当前 pane，或同步输入开启时的当前标签页已连接 pane。按 `Ctrl+Enter` 发送，按各目标终端的 bracketed-paste 模式包装，且不会额外追加回车；按 `Esc` 放弃。
- 按 `Ctrl+G` 后按 `Ctrl+F`，或在 pane 菜单中选择“发送文本文件到终端”，可把本地文本逐行写入当前 pane。可自动检测或手选源文件编码，并选择终端编码（UTF-8、GBK、GB18030、Big5、Shift_JIS、Windows-1252）；发送前显示解码后的预览，无法转换的字符会报错。还可设置字符/行间隔（毫秒），或填写远端提示符，让发送在每行后等待提示符，并设置 1–300 秒超时。确认后换行统一转换为回车，单文件限制 8 MiB，含 NUL 的文件会被拒绝并建议改用 SFTP/SCP。发送期间按 `Esc` 取消。同步输入打开时仍只发送到当前 pane；延迟和编码选项按每次发送设置，暂不持久化。
- SSH pane 中按 `Ctrl+G` 后按 `l`，或在 pane 菜单选择“SSH 转发管理”，可打开转发管理器。按 `N` 配置本地端口转发，按 `R` 配置远程端口转发，按 `S` 配置 SOCKS5 动态代理。远程转发默认监听 SSH 服务器的 `127.0.0.1:8080`，目标是运行工作台的本机 `127.0.0.1:22`；服务器需允许远程转发。SOCKS5 默认监听本机 `127.0.0.1:1080`，只允许监听本机回环地址；SOCKS5 TCP 目标由 SSH 服务器侧连接，域名也在远端解析。管理界面可查看并停止转发；选中运行中的规则按 `P` 保存后，会在该主机下次 SSH 连接时自动恢复。按 `Tab` 在运行中规则、活动通道与已保存规则间循环；活动通道列表显示路由、存续时间及双向字节数，按 `Enter` 或 `X` / `D` 单独关闭选中通道且不停止监听器；在已保存列表按 `Enter` 启停，按 `X` / `D` 两次确认删除规则。删除保存规则不会关闭当前正在运行的转发；关闭 SSH 会话会清理其运行中的监听器。
- SSH / Telnet / Rlogin / 串口或本地终端断开后，在对应 pane 按 `Ctrl+G` 后按 `r` 可重新连接或启动 Shell；SSH 重连会重新执行主机指纹校验和身份验证。对 SSH pane 按 `Ctrl+G` 后按 `z` 可开启或关闭自动重连，也可从 pane 右键菜单切换。只在 SSH transport 异常中断时自动重试，正常 Shell 退出不会触发；每次间隔为 1、2、4、8、16 秒，最多 5 次。需要认证时仍会向用户询问密码、密钥口令或新的主机指纹确认；当前开关仅在本次工作台运行中有效，不持久化。
- 在支持把右键事件传给 TUI 的终端里，右键 pane 或标签也可打开对应菜单；菜单可用鼠标点击，也可用 `↑` / `↓` 和 `Enter` 操作。GoLand 集成终端会先显示自己的右键菜单时，用 `Ctrl+G` 后按 `m` / `t` 打开应用菜单。
- `Ctrl+]` 也可关闭当前 pane；当前标签最后一个 pane 关闭后会关闭标签。返回主机列表时，所有打开的会话继续运行；选中另一台主机按 `Enter` 可再开一个标签。
- 从主机列表选择 SSH/SFTP、SSH/SCP 或 FTP/FTPS 主机并按 `f` 可独立连接并打开双栏文件面板；左栏默认是本地目录，右栏是远程目录。按 `c` 可把左栏切换为另一台 SSH/SFTP、SSH/SCP 或 FTP/FTPS 主机，支持同协议与混合协议的远程到远程文件和目录传输。两端均为明文 FTP 时会尝试 FXP 服务器直传，服务器不支持或安全协商不满足时自动回退到本机临时文件中转；FTPS 和混合协议传输仍使用本机中转。FXP 直传和拒绝 `PORT` 后的回退已通过两个独立的 pyftpdlib 2.2.0 服务端验收。按 `b` 可断开左侧远程主机并恢复本地目录。左右栏都连接远程主机时，按 `y` 开启或关闭同步浏览；开启时以当前两侧目录为映射根，进入或返回目录会按相同相对路径同步切换，任一侧目录不存在或越过映射根时两栏都保持不变。按 `Tab` / `←` / `→` 切换焦点，使用 `↑↓` / `j` / `k` 选择、`Enter` 进入目录、`Backspace` 返回上级；按 `/` 可递归搜索当前栏的文件名（忽略大小写），支持取消和结果上限，选中结果按 `Enter` 会进入其所在目录并定位文件。按 `f` 可过滤当前栏项目，例如 `*.go, !*_test.go, type:file`；支持大小写不敏感 glob、逗号分隔的多个规则，以及 `type:file`、`type:dir`、`type:link`、`type:special`、`size>=1MiB`、`mtime>=2025-01-01T00:00:00Z` 和 `perm=0644` 等规则；SFTP 服务端返回属主属性时还支持 `uid=1000`、`gid>=1000`，缺失属性时不会显示或匹配 UID/GID。大小单位支持 B、KiB、MiB、GiB，修改时间使用 RFC3339，权限要求远端提供可信 rwx 元数据。每条正向大小、时间或权限条件都必须满足，`!` 可排除命中的项目；FTP 未提供权限时不会匹配 `perm` 条件；UID/GID 过滤仅在 SFTP 服务端提供相应属性时可用。需要自定义组合逻辑时在规则前加 `expr:`，例如 `expr:(type:file && size>=1MiB) || name:*.log`；支持括号、`!`、`&&`、`||`，优先级依次为 `!`、`&&`、`||`。过滤输入框按 `Ctrl+R` 可在当前目录过滤和递归过滤间切换；递归过滤复用相同表达式；不含 `/` 的 glob 按文件名匹配，含 `/` 的 glob 按相对于递归根目录的路径匹配，结果最多 1000 项、最多遍历 100000 个目录和 1000000 个条目，跳过符号链接目录，按 `Enter` 可定位结果。按 `Ctrl+S` 可保存过滤表达式为本地命名方案；按 `F` 浏览、应用或删除方案。空条件清除当前目录过滤；已保存方案保存的是表达式，应用范围仍由过滤输入框的 `Ctrl+R` 选择。按 `=` 比较两栏目录，按 `Tab` 或方向键选择左→右或右→左，再按 `Enter` 生成同步队列；按 `b` 查看双向方案，较新文件优先；时间相同但属性不同的冲突可选中后按 `l` 选择左栏、按 `r` 选择右栏作为来源、按 `x` 清除选择。应用选择前仍会对已存在目标逐项确认覆盖。双向模式不删除任一侧文件；类型冲突和不支持的文件类型仍需手动处理。比较依据名称、类型、大小、修改时间和 rwx 权限。默认是合并模式，保留目标侧多余文件；按 `m` 切换到镜像模式后，会显示多余项目的删除清单，输入 `y` 二次确认才会执行。删除前会重新扫描并核对清单，若目标内容发生变化会取消删除；同步传输失败、跳过或取消时也不会删除。目录删除不会跟随符号链接，特殊文件不会自动删除。按 `Space` 标记或取消标记项目，再按 `u` 将左栏所选项目传到右栏，按 `d` 将右栏所选项目传到左栏；没有标记项时只传输当前选中项。多选传输会先进入队列预览，按 `↑` / `↓` 选择项目、按 `+` 提前或 `-` 延后调整优先级、按 `Enter` 开始、按 `Esc` 取消；确认前取消会保留已标记文件。当前栏选中文件后按 `i` 查看文件属性（类型、路径、大小、修改时间、权限及服务端提供时的 UID/GID），按 `v` 预览或 `e` 编辑，编辑器会显示本地或远程主机身份。按 `p` 打开权限修改，例如输入 `644` 或 `0755`；服务端/文件系统提供实际权限时会预填当前值，未知时文件和目录分别以 `644`、`0755` 作为可编辑起点；仅普通文件和目录可修改。FTP/FTPS 没有标准权限命令；Unix `LIST` 返回权限时会显示实际 rwx，按 `p` 使用 `SITE CHMOD` 请求修改，服务端可能拒绝；其他列表格式不会推断权限。队列按名称顺序检查目标冲突并逐项询问；确认后最多并发传输 3 项。已存在目标可按 `y` 覆盖、其他键跳过、按 `q` 取消队列；传输中按 `Space` 暂停/恢复，按 `Esc` 取消当前队列。暂停在当前文件的下一数据块或目录检查点生效。`m` 在当前栏新建目录、`n` 重命名、`x` 删除、`r` 刷新。删除前会明确提示；确认后目录递归删除，符号链接只删除链接本身。单击选择、双击进入目录，滚轮移动选择。按 `Esc` 返回主机列表。
- 在 SSH pane 中按 `Ctrl+G` 后按 `f`，或打开 pane 菜单并选“打开远程文件管理”，可复用当前 SSH 连接查看单栏远程文件。SFTP 主机使用 SFTP 子系统，SCP 主机使用远端 POSIX shell 查询目录和流式传输文件。按 `/` 可递归搜索当前远程目录下的文件名（忽略大小写），选中结果按 `Enter` 会进入其所在目录并定位文件；搜索中可按 `Esc` 取消。按 `u` 输入本地路径上传，按 `d` 下载所选远程项；`i` 查看属性、`v` 预览、`e` 编辑、`n` 重命名、`p` 修改权限、`m` 建目录、`x` 删除、`r` 刷新，`Esc` 返回终端。本地终端不支持此入口。
- SFTP/SCP 支持本地到远程、远程到本地和远程到远程的普通文件及目录递归传输，并显示字节进度；递归目录传输还会显示当前相对文件路径和已完成文件数；FTP/FTPS 目录传输也显示相同信息。传输会保留源端 rwx 权限和修改时间。独立双栏面板支持多选、按名称排序、逐项覆盖确认和最多 3 项并发传输；跳过冲突、暂停/恢复、取消队列和失败后继续均可用。传输中 `Space` 暂停或恢复，`Esc` 取消；暂停在当前数据块或目录递归检查点生效，正在进行的网络读取完成后才会停在下一检查点。SFTP 单文件使用隐藏临时文件提交；取消或网络中断后会保留临时文件，下次传输时校验源文件前缀后自动续传，校验不匹配则从头开始。SCP 单文件上传和下载也使用隐藏临时文件提交，并在取消或网络中断后保留临时文件；下次传输校验文件前缀后自动续传，SHA-256 工具缺失或校验不匹配时使用新的暂存名从头开始。SCP 递归目录下载会为每个文件执行同样的续传校验，已完成文件在内容完全匹配时跳过；工作台只在本次目标目录具有有效续传标记时允许无覆盖重试。目录传输逐文件提交，失败或取消后已完成文件和可续传的暂存文件会保留。文件列表采用 Yazi 风格：目录优先、按类型区分图标、常用大小和修改时间靠右，整行突出当前选择；宽面板显示权限与属主，完整属性按 `i` 查看。按 `p` 可修改本地或远程普通文件、目录权限；FTP/FTPS 使用非标准 `SITE CHMOD` 扩展，服务端可能拒绝，应用后会重新读取列表验证结果；不支持的权限值与文件类型会报错。符号链接会显示但不会自动跟随或传输；递归删除会删除符号链接本身，不会跟随链接。本地栏及两侧远程栏均支持受大小限制的多编码文本预览和基础编辑。自动识别 UTF-8/UTF-8 BOM、带 BOM UTF-16/32 LE/BE、GBK、GB18030、Big5、Shift_JIS、Windows-1252；无 BOM UTF-16/32 仅在 ASCII 字节模式明显时启发式识别。按 `Ctrl+U` 可切换编码，保存按当前编码写回并保留原 BOM 状态；切换编码时使用目标编码默认的 BOM 规则。明显二进制内容会拒绝打开。编辑缓冲区内部使用 UTF-8，并保留原有混合换行符；新增行采用原文件最常见的换行格式。编辑时支持未保存修改确认、保存冲突检测和临时文件提交；本地保存会保留文件权限。编辑模式按 `Ctrl+E` 可用按 `E` 设置的本地编辑器命令（未设置时回退至 `$VISUAL` 或 `$EDITOR`）在本地 0600 临时副本中编辑，结果先进入缓冲区，再按 `Ctrl+S` 保存；按当前工作区前缀后按 `e`（默认 `Ctrl+G` 后按 `e`）可直接编辑并在外部编辑器退出后自动保存，外部编辑器键也可通过 `workspace.bindings.external_edit` 调整；仍会检查文件冲突和内容合法性。内置编辑器按 `Ctrl+F` 查找、`Ctrl+N` 跳到下一个匹配、`Ctrl+R` 打开替换；替换输入框中按 `Enter` 替换当前匹配，按 `Ctrl+Enter` 全部替换。查找和替换不区分大小写，搜索会循环并定位匹配行；语法高亮按扩展名识别 Chroma 支持的文件类型，未知扩展名保持纯文本；非 ASCII 主导的无 BOM UTF-16/32 识别和更多字符集仍待完善。
- 图片文件（PNG/JPEG/GIF/WebP/BMP/TIFF/AVIF/HEIC/SVG/ICO）按 `v` 通过本地编辑器预览，按 `e` 编辑。在 SFTP 文件列表按 `E` 可设置统一的本地外部编辑器命令（例如 `goland --wait` 或 `code --wait`）；设置保存在本机 SQLite，文本和图片外部编辑都会优先使用它。留空可清除应用设置并回退到 `SFTP_IMAGE_EDITOR`、`VISUAL` 或 `EDITOR` 环境变量；macOS 未配置时，图片预览 `v` 会使用系统默认图片应用。远程图片会流式下载到本机临时目录，不受文本编辑器 1 MiB 限制；远程编辑退出后检查图片是否改变，并核对远端文件大小、修改时间和权限后再上传。macOS 上设置命令为 `goland` 时会自动从 GoLand.app 中查找启动器，不要求 `goland` 已加入 PATH；未显式提供时会自动补上 `--wait`，确保编辑结束后再检查并上传。上传失败或远程版本冲突时会保留临时副本并显示本地路径。
- 每个 pane 的按键输入、粘贴、VT 输出、鼠标模式和窗口尺寸独立转发到各自 PTY。远端程序启用鼠标模式时转发鼠标事件；按住 `Shift` 拖动由工作台创建应用内选区，避免与远端鼠标跟踪冲突。复制优先写入本机剪贴板并回退至 OSC 52；粘贴可从终端剪贴板读取，也可使用外层终端原生粘贴事件。
- 本地终端通过 Unix PTY 启动交互式登录 Shell；Windows 使用 ConPTY，优先启动 `SHELL`，否则启动 `COMSPEC`（默认 `cmd.exe`）。关闭 pane / 标签或退出工作台时会结束对应的本地 Shell 进程。PTY 后端支持 macOS、Linux、FreeBSD、DragonFly BSD、OpenBSD、Solaris 和 Windows；Windows 仍需在真实系统上完成交互运行验证。

在独立双栏文件面板中按 `B` 管理目录书签：先用 `Tab` / `←` / `→` 选择本地或远程栏，按 `B` 后按 `a` 保存当前目录并输入书签名称；选中书签按 `Enter` 跳转，按 `d` 再确认删除。书签只保存在本机 SQLite；本地书签可在各会话间复用，远程书签按保存主机或临时连接端点隔离，不包含密码，也不会随会话目录导出。

主机指纹保存在系统用户配置目录下 `tui-ssh-workbench/known_hosts`。
