| 文件/串口传输 | 部分完成 | SFTP、SCP 和 FTP/FTPS（明文、显式 TLS、隐式 TLS）已接入文件工作区；FTP 凭据不落盘，控制连接和数据连接均使用配置的 TLS。终端文本文件发送已实现：支持源文件编码自动检测或手选、UTF-8/GBK/GB18030/Big5/Shift_JIS/Windows-1252 终端编码转换、预览确认、换行转回车、字符/行间隔、按提示符等待和取消；源文件编码及终端编码、延迟设置均按每次发送选择。ZMODEM 已接入终端输出探测、路径确认、接收覆盖策略、进度/取消、单文件及多文件发送和批量接收；发送面板可粘贴多行路径或用 `Ctrl+J` 分行。协议支持 16/32 位 CRC，外部 `lrzsz` 的 `lrz`/`lsz` 双向互操作已通过；更多 ZMODEM 实现/终端仍需验收。XMODEM/YMODEM 协议状态机和终端面板已实现，支持 XMODEM CRC/校验和发送、XMODEM 单文件收发、YMODEM 批量收发、重试、取消、安全文件名和原子落盘；协议往返测试及基于 `lrx`/`lsx`/`lrb`/`lsb` 的 PTY 外部四方向互操作均已通过。XMODEM 没有文件长度元数据，标准接收端会保留末块 `0x1a` 填充，不能保证接收文件长度和源文件一致；接收方向会剥除尾部填充，因此源文件以 `0x1a` 结尾时存在固有限制。SFTP/SCP 工作区已通过本机 OpenSSH 9.9 服务端验收；pyftpdlib 2.2.0 明文 FTP、显式 FTPS 与隐式 FTPS 的主动/被动模式外部服务端互操作已通过，其他服务端仍待验收。 |
| 外观与快捷键 | 部分完成 | 会话工作区的快捷键前缀和前缀动作可在 TOML 中自定义，并在工作区帮助和 pane 菜单中显示实际键位；TUI 支持 default、Nord、Dracula、Solarized Dark 和高对比配色，并允许在 TOML 中覆盖界面颜色；终端键盘映射已支持 TOML 覆盖 F1–F20、Backspace/Delete 序列和 Alt/Meta ESC 前缀行为。状态栏活动会话、收发字节及快捷提示项可在TOML中排序和隐藏，搜索、报错、录制等临时状态优先显示；屏幕锁定、验证/更改/移除锁屏密码和可选空闲自动锁屏已实现，钥匙串只保存 scrypt 校验值。配色方案专用导入/导出不单独实现，定制颜色通过 TOML 管理；字体、光标形状和像素级外观控制由终端模拟器负责，不纳入 TUI 范围。 |

日志浏览器现支持按文件名筛选、安全预览和删除单个日志分段；删除前二次确认，仍在记录的会话不可删除。全局容量及过期时间清理策略已实现，默认容量 1 GiB、保留 90 天。

插件扩展能力属于本项目架构目标，不是 Xshell/Xftp 的产品功能对照项：编译期 Go 插件和可搜索的异步命令面板已实现；外部进程隔离、能力授权、插件目录管理和兼容性策略仍待实现。

## 当前优先级

先补足 TUI 内的跨平台日常操作和数据安全，再做协议与自动化扩展；桌面通知等不属于 TUI 的项目不作为阻塞项：

1. 命令历史、日志列表与 VT 安全预览、单 pane 输出记录、有界正则脱敏与分段轮转、终端基础文本/矩形选区与 OSC 52 剪贴板、当前标签页同步输入、快速命令、Compose Pane、会话收藏/最近连接和有上限的单 pane SSH 自动重连已实现。
2. 扩大 Xftp 服务端互操作覆盖；pyftpdlib 2.2.0 明文 FTP、显式与隐式 FTPS、明文 FTP FXP 直传及拒绝 FXP 后的本机中转回退，以及 OpenSSH 9.9/zsh 的 SFTP/SCP 已通过外部服务端验收。其他 FTP/SCP 服务端仍需验证。递归目录进度、搜索、过滤、方向选择式合并、基于修改时间的双向同步、可选镜像同步、队列优先级和暂停/恢复队列已实现。
3. 可复用 SSH 认证配置档、按主机保存/读取系统钥匙串凭据、SSH 连接超时与 keepalive 参数配置、通用 JSON 会话目录导入导出、Xshell `.xsh` 目录导入导出已实现；主密码保护仍未实现。
4. 扩大其他 FTP/FTPS 服务端和公开站点互操作验收；串口流控与 Xshell 原生 SERIAL 映射已接入，仍需实体硬件验收，并用 Xshell 客户端验收原生会话导入导出；Telnet 与 Rlogin 仍需真实服务器互操作验收；扩大 ZMODEM、XMODEM/YMODEM 在其他实现和终端上的互操作，再评估 SSH1/RDP 等协议和更多认证/代理能力。
5. 外部插件隔离与能力授权、主题/快捷键定制、跨平台发行与实机验收；编译期插件命令面板已实现。

每项完成后都要补主流程、失败、取消和权限边界测试；桌面特有能力只有在能形成自然、可操作的 TUI 等价交互时才纳入计划，否则按范围排除并写明原因。
